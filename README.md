# Malta International Medical Centre (student demo)
1. Install VS Code and the "Live Server" extension (Ritwick Dey).
2. File > Open Folder > select this folder.
3. Right-click index.html > "Open with Live Server".
No Live Server? Double-click index.html; it still works.
Photos load from Unsplash links in index.html. For offline use, download them into /images and change each src to images/your-file.jpg.
